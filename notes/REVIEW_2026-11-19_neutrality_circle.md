# Neutral points on the rational unit circle: reflection, congruences, prime-value families, and why they miss the orbit

Status: derived with a language model, 19 November 2026; no human has checked it. No consequence for Problem H. The paper is not changed. Code: code/verify_neutrality_circle.py (standard library, about 1 second; in CI). Sources: an owner-supplied Magma V2.30 run (two byte-identical attachments) with an analysis text, and an owner-supplied argument that two prime-value families miss the orbit (reviewed here).

## Definitions
t = u/v in lowest terms, (a, b, c) = ((v^2 - u^2)/d, 2uv/d, (v^2 + u^2)/d) with d = gcd in {1, 2}; F = 4a^3 + 27 b^2 c; D = ab. A circle point is neutral if no prime p >= 5 dividing F has (D/p) = +1, equivalently every local root number at the primes p >= 5 dividing F is +1 (w_p = -(ab/p)); then W(E_t) = f(t). On the orbit, neutral at n means Q_n is empty. Among the 19 completely factored members, Q_n is empty exactly for nP, n = 9, and nP + T, n = 3 (checked). The word "neutral" is not used in the paper.

## The Magma run
The two attachments are byte-identical; the listing shows only the first 30 of the 154 points with a neutral member (v <= 16), then the totals. All 30 entries and the summary reproduce exactly (662 points, 174 neutral, 0.2628; pairs both / only B+ / only B- / neither = 20 / 71 / 63 / 177). Scope: the run covers only t = u/v with u + v odd (d = 1, a odd, 4 | b), which is 331 of the 489 coprime pairs u < v <= 40; the 158 pairs with u, v both odd (d = 2) are not tested (77 of 316 points are neutral there).

## Reflection proposition (correct)
t -> -t changes b to -b and D to -D and leaves F unchanged. For p >= 5 dividing F one has p not dividing ab (p | a would force p | 27 b^2 c), so (-D/p) = (-1/p)(D/p). Hence both reflected points are neutral if and only if every prime p >= 5 dividing F satisfies p = 1 mod 4 and (D/p) = -1. This is the neutral-point corollary of the identity already in the paper (Pairs (t, -t): w_p(t) w_p(-t) = (-1/p) for p | F). It explains the table: a B+ neutral point is also neutral under reflection exactly when all its candidate primes are 1 mod 4 (20 of 91; the other 71 have a prime = 3 mod 4).

## Sharp congruence (strengthens the analysis text)
F/4 = a mod 4 for u + v odd (correct). Write F = 2^al 3^e m with m prime to 6. Both neutral forces every prime of m to be 1 mod 4, so m = 1 mod 4, hence: for u + v odd, a = (-1)^e (mod 4); for u, v both odd (F = 3 mod 4, because c = 1 mod 4 there), e must be odd. Also 3 | F exactly when 3 | a (then 27 | F). So if 3 does not divide a, both-neutral needs u + v odd and v odd, u even; it is impossible for u, v both odd. Checked on every both-neutral pair with v <= 100 (123 + 51 pairs): no violation. Necessary, not sufficient.

## Neutral fractions
Neutral points as a fraction of all points: u + v odd: 0.263 (v <= 40), 0.249 (v <= 80), 0.238 (v <= 120); u, v both odd: 0.244, 0.246, 0.236. Heuristic, not proved: each prime is "+1" with probability 1/2 and the number of primes grows like log log, so the neutral proportion should decay like a power of 1/log; the count still grows. The 26% must not be extrapolated.

## Infinitely many neutral circle points: not provable unconditionally with known methods
- F = +-2^al 3^be (no prime >= 5) is a Thue-Mahler equation: finitely many solutions.
- A sieve (dimension 1/2, sifting out the primes with symbol +1) would have to sift every prime up to sqrt(F) of size X^3 for u, v <= X, while the level of distribution is about X^(2-eps): out of range. Sieves give almost-primes, not "all prime factors good". The symbol of the last large prime factor is tied by Hilbert reciprocity to the parity of the rest, the same kind of wall as Problem H.
- No algebraic identity forces all primes to be inert (norm forms force them to split).
- The one concrete route is prime values of F''(u,v) (F'' = part of |F| prime to 6), which is open (even for n^2 + 1; binary forms are known only for cubics, from memory: Heath-Brown, Heath-Brown-Moroz), and F(u,v) = f(u^2, v^2) with f cubic is not covered.

Conditional theorem. On a line the symbol (ab/N), N = F'', is periodic because ab splits into linear factors and F is constant modulo each: along t = 1/(12k) the symbol is -1 for every k (checked k < 3000), and along t = u = 6w it depends only on u mod 24 (-1 for u = 0, 12; +1 for u = 6, 18). So: if F(1, 12k) is prime for infinitely many k, or F(u, 1) is prime for infinitely many u = 0 mod 12, there are infinitely many neutral circle points (Bunyakovsky-type input, open). Data: t = 1/(12k), k < 6000: F'' prime (probable prime) for 442 values, all neutral; t = 6w <= 120000: F'' prime for 1385, neutral for 702. The reflected t = -1/(12k) has symbol +1, so that family is one-signed. For general coprime (u, v) the symbol is not periodic (fraction -1: 0.50002 on 194390 pairs; conflicts modulo every modulus up to 576 tried), so extending beyond lines needs prime values with a quadratic-character condition at varying modulus.

## Negative result: these families miss the orbit (argument supplied by the owner; verified, extended)
Claim: 1 - x(Q) = 1/(12k), k >= 1, has no solution Q in C(Q) (C: y^2 = x^3 - 2x^2 + 2x). Proof: x of a rational point on an integral model has a square denominator; x = (12k - 1)/(12k) in lowest terms forces 12k = s^2, so 6 | s; then (s^3 y)^2 = (s^2 - 1)(s^4 + 1) = 2 (mod 3), not a square. For t = 12k: x = 1 - 12k < 0 and C(R) has x >= 0 (x((x-1)^2 + 1) < 0 for x < 0), so every point has t = 1 - x <= 1. Both families are therefore disjoint from the orbit branches nP and nP + T (for every n), unconditionally and without Faltings.
Extensions (checked, code/verify_neutrality_circle.py): the reflected parameters are also excluded: t = -12k needs (1 + u)(1 + u^2) = square with gcd 1, so 1 + u^2 = square, impossible for u > 0; t = -1/(12k): 12k = s^2 and s even give coprime (s^2 + 1), (s^4 + 1), so s^2 + 1 = square, impossible. Integral t on C with |t| <= 2*10^5: only -7, -1, 0, 1 (x = 8, 2, 1, 0).
General criterion: t = u/v (lowest terms) equals 1 - x(Q) for some Q in C(Q) iff v = s^2 and (s^2 - u)(s^4 + u^2) is a square. For fixed u this is a genus-2 curve in s (finitely many s, Faltings); for u = 1 it is elementary. The same holds for a nonconstant polynomial family t = phi(s) of degree >= 2: y^2 = (1 - phi)(1 + phi^2) has degree 3 deg phi, genus >= 2 when squarefree (the factors are coprime; the squarefree case is generic, not checked case by case). All 80 orbit points (n <= 40, both branches) have a square denominator and t <= 1. Conclusion: a conditional infinitude argument for the orbit cannot come from a family of parameters; it has to use the group law of C.

## What it rests on
Exact integer arithmetic and Pollard-rho factorizations; Miller-Rabin with fixed bases (deterministic below 3.3 * 10^24, so the largest values in the family counts are probable primes); the finite searches are evidence, not proofs; the heuristics are marked.
